# 📚 Library App

A small application to track books in a personal library. This project was a deep dive into **JavaScript Objects** and **Object Constructors**.


## 🎯 Features

* **Add Books**: Users can input title, author, pages, year and read status.
* **Read Toggle**: Ability to toggle the "Read/Not Read" status of a book dynamically.
* **Delete**: Remove books from the collection.
* **Local Storage**: Data persists in the browser so books remain after refreshing the page.

## 🛠️ Built With

* **HTML5 / CSS3**
* **JavaScript** (Prototypes & Constructors)

## 🧠 What I Learned
* Using **Object Constructors** and **Prototypes** to create book instances.
* Understanding the difference between `this` context in different functions.
* Manually managing an array of objects and rendering them to the DOM.
