# ✂️ Rock Paper Scissors

The classic game played against the computer. This was the first JavaScript project in the curriculum, revisited later with a UI.


## 🎯 Features

* **Game Loop**: First to 5 points wins.
* **Dynamic UI**: Updates the score and announces the winner of each round on the screen.
* **Randomizer**: Computer makes a random choice between Rock, Paper, and Scissors.

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**

## 🧠 What I Learned
* Writing basic functions and conditional statements (`if/else`).
* Understanding `Math.random()` implementation.
* Interacting with the DOM to display results instead of using `console.log`.
